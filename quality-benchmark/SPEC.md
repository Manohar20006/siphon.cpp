# Task Board Benchmark

Build a dependency-free static task board with `index.html`, `styles.css`, and
`script.js`.

Requirements:

1. Add a task through a text form; trim whitespace and reject empty tasks.
2. Render tasks with completion checkbox and delete button.
3. Support All, Active, and Completed filters.
4. Show remaining active count and total count.
5. Provide a Clear completed button that is disabled when none are completed.
6. Persist tasks and the selected filter in localStorage.
7. Use semantic controls, visible keyboard focus, and an `aria-live` status.
8. Work at mobile widths without horizontal overflow.
9. Use no external assets, libraries, network requests, or build step.
